# memengine

Mini site + product draft for a curated meme subscription service.

## What it is
A controlled alternative to social media feeds:
- funny memes delivered by email or text
- 5-day or 7-day packages
- quantity-based pricing
- genre selection
- branded share pages that keep the subscription CTA attached

## What’s in this repo
- `index.html` — the draft mini site

## Next step
Turn the static concept into a real app with:
1. content model
2. subscription flow
3. branded meme page
4. delivery pipeline
5. tracking / referrals
